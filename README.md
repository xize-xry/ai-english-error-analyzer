# 英语错题分析系统

结合英语教学场景开发的 AI 应用原型，将单次错题分析保存为结构化记录，
按学生统计累计错误分布，并结合近期错题生成学习建议。

## 技术栈

Python、FastAPI、MySQL、PyMySQL、DeepSeek API、
HTML、CSS、JavaScript。

## 已实现功能

- 输入题目、学生答案及参考答案，生成错因和学习建议。
- 使用固定的七类错误分类，并校验 AI 返回结构。
- 将错题及分析结果保存到 MySQL。
- 按学生编号查询历史，支持错误类型筛选。
- 统计各类错误数量和占比，在网页展示画像。
- 根据累计统计与最近最多十条错题生成复习方向和三项训练任务。
- 提供输入校验、处理中状态和请求失败提示。

## 本地运行

以下命令在项目目录执行。开发时使用 Python 3.12、MySQL 5.7.25，
数据库地址为 127.0.0.1:3366。

### 1. 创建虚拟环境并安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### 2. 初始化数据库

连接 MySQL，按提示输入密码；无密码时直接回车：

```powershell
mysql -h 127.0.0.1 -P 3366 -u root -p
```

在 mysql 提示符中执行：

```sql
SOURCE D:/ailianxi/schema.sql;
```

如果项目位于其他目录，修改上述路径。

### 3. 配置环境变量

在项目根目录创建 .env：

```dotenv
DEEPSEEK_API_KEY=填入自己的API密钥
MYSQL_PASSWORD=填入自己的数据库密码
```

数据库无密码时，MYSQL_PASSWORD 留空。
数据库主机、端口、用户名和库名目前配置在 database.py 中。
模型名称配置在 ai_service.py 中，需使用账号支持的模型。

### 4. 启动

```powershell
python -m uvicorn api:app --reload
```

网页：http://127.0.0.1:8000/
接口文档：http://127.0.0.1:8000/docs

## 演示步骤

1. 使用 student_001 录入一道错题。
2. 查看 AI 返回的分类、错因和建议。
3. 查看历史记录及累计错误画像。
4. 点击“生成学习建议”，查看复习方向和训练任务。
5. 切换到无记录的学生编号，验证查询结果分开。

## 已完成的本地手动验证

- 错题分析、保存、历史查询和画像展示。
- 四条演示记录统计为 2、1、1，占比为 50%、25%、25%。
